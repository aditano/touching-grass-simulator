# Touching Grass

A small outdoor simulator. Touch the grass. That's the assignment.

**Play it:** [aditano.github.io/touching-grass-simulator](https://aditano.github.io/touching-grass-simulator/)

Drag through the field. Blades bend, a streak climbs, and serotonin does its little best.

## Run

```bash
npm install
npm run dev
```

Local play is at http://localhost:5173/touching-grass-simulator/ — same path the live site uses.

## Touch grass

| Input | What happens |
| --- | --- |
| Drag or swipe | Brush the grass |
| Tap | Poke one patch |
| M | Mute the rustle |

Phone portrait is the real way to play. A mouse works too.

## Stack

Vite, TypeScript, and Three.js. Nothing to install beyond the page, and no accounts.
