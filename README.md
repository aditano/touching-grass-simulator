# Touching Grass

A small browser game about a late-afternoon meadow. Drag through the field and the grass bends under your hand. A streak climbs, a serotonin meter fills, and the page keeps score while you stay.

Play the live site: [aditano.github.io/touching-grass-simulator](https://aditano.github.io/touching-grass-simulator/)

The page runs in the browser. It stores your best streak and mute setting in local storage on this device.

## Features

- Drag, swipe, or tap the field. Blades bend away from each touch and spring back when you let go. Up to six touches count at once.
- Wind moves the grass on its own. A mouse hover shows a soft ring before you press.
- The heads-up display tracks touches, the current streak, your best streak, a serotonin mood, and how long you have been outside.
- A streak keeps growing while you brush and resets after a short pause. The best streak is saved on this device.
- Serotonin rises as you touch the grass and slowly settles. The mood label moves from idle to stirring, decent, glowing, lush, and feral.
- Short lines show up on the first touch, on later pokes, when you beat your streak, and at one, three, and ten minutes outside.
- The scene is a golden-hour meadow: sky and sun, hills, trees, wildflowers, drifting motes, butterflies, and a bird that crosses now and then.
- Each touch kicks up a small puff and plays a rustle over a soft wind. The mute button, or the M key, turns sound off. That choice is remembered.
- The camera is framed for a phone held upright and pulls back on wider screens. Phones and smaller machines draw 8,500 blades. Larger desktops draw 16,000.
- If the browser asks for reduced motion, wind, camera sway, and the animals slow down.
- If WebGL is unavailable, the page says so.

## Run locally

Use Node.js 20.19 or newer, or Node.js 22.12 or newer. The GitHub Pages build uses Node.js 22.

```bash
npm install
npm run dev
```

Open [http://localhost:5173/touching-grass-simulator/](http://localhost:5173/touching-grass-simulator/). The dev server uses the same `/touching-grass-simulator/` base path as the live site.

| Command | What it does |
| --- | --- |
| `npm run dev` | Serves the game at port 5173 |
| `npm run build` | Typechecks, then writes the static site to `dist/` |
| `npm run preview` | Serves `dist/` at [http://localhost:4173/touching-grass-simulator/](http://localhost:4173/touching-grass-simulator/) |
| `npm run typecheck` | Runs the TypeScript checker |

## How to play

| Input | What happens |
| --- | --- |
| Drag or swipe | Brush the grass |
| Tap or click | Poke one patch |
| Hover with a mouse | A ring follows the cursor |
| Mute button or M | Mute or unmute the wind and rustle |

## Tech stack

- [Vite](https://vite.dev/) 8 serves the page in development and builds the static site.
- [TypeScript](https://www.typescriptlang.org/) 5.8 types the source. The build runs `tsc --noEmit` before bundling.
- [Three.js](https://threejs.org/) 0.185 draws the meadow: instanced grass, a shader sky, hills, trees, and flowers.
- The Web Audio API synthesizes the wind and the rustle.
- [GitHub Actions](.github/workflows/pages.yml) publishes `dist/` to GitHub Pages on every push to `main`.
